💡 Como fazer um vídeo bolinha NATIVO (igual gravado pelo Telegram)?
Caminho 1 — Mais fácil (recomendado):
  1. Abra o Telegram no celular
  2. Em qualquer chat, segure o ícone do microfone (canto direito) → desliza pra cima pra travar
  3. Toca no ícone de câmera pra mudar pra vídeo → grava sua bolinha (até 60s)
  4. Manda pra "Mensagens Salvas"
  5. Clica direito no vídeo → Salvar como → escolhe local → o arquivo .mp4 baixado JÁ tá no formato perfeito
  6. Faz upload aqui marcando "Vídeo bolinha"
Caminho 2 — Outro vídeo qualquer:

O bot tenta processar automaticamente com ffmpeg (recortando quadrado e otimizando). Pra isso funcionar, você precisa ter ffmpeg instalado:

  • Windows: baixe em gyan.dev/ffmpeg → coloque ffmpeg.exe no PATH (ou na pasta do projeto)
  • Linux/Mac: apt install ffmpeg ou brew install ffmpeg

Sem ffmpeg, o vídeo é enviado do jeito que tá — pode sair grande/feio se não for quadrado.
